# 🐦 Flappy Bird — Python

A Flappy Bird clone built in Python using **Pygame**, fully generated by [Claude](https://claude.ai) (Anthropic's AI assistant).

---

## 🤖 About this project

This project was entirely written by an AI. The code, comments, and structure were generated through a conversation with Claude — no manual coding involved. It's a great example of what AI-assisted development looks like in practice.

---

## 🎮 How to play

| Control | Action |
|---|---|
| `Space` or `↑` | Flap |
| Left click | Flap |
| `ESC` | Quit |

Pass through the gaps between pipes without hitting them or the ground. Each pipe you clear gives you **1 point**.

---

## ⚙️ Requirements

- Python 3.8 or higher
- Pygame

---

## 🚀 Installation & usage

**1. Clone the repository**
```bash
git clone https://github.com/xavibada/Flappy-bird.git
cd Flappy-bird
```

**2. Install the dependency**
```bash
pip install pygame
```

**3. Run the game**
```bash
python flappy_bird.py
```
